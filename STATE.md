# Implementation State

- Next.js App Router with TypeScript, Tailwind CSS, and Framer Motion.
- One page with anchored sections and a shared content frame.
- Static export to `out/`, deployed through one GitHub Pages workflow.
- Monogram favicon and portrait-based social previews.
- Profile content in `content/profile.ts`; navigation and social links in `content/site.ts`.

## Local Validation
Run `npm run typecheck` and `npm run build` before publishing changes. A local build does not confirm the status of the deployed website.
