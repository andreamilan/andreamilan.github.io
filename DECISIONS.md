# Architecture Decisions

- Use a single page with anchored sections.
- Export static files for GitHub Pages; avoid server-dependent features.
- Deploy through one GitHub Actions workflow.
- Keep profile content separate from layout and motion components.
- Use dark editorial styling and a consistent section frame after the hero.
- Feature the current role; keep earlier roles compact and education separate.
- Use LinkedIn for contact and Medium as a secondary link.
- Keep contact forms and downloadable personal documents out of the site.
- Respect `prefers-reduced-motion` in animations and scrolling.
